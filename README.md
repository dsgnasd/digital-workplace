# Digital Workplace — прототип портала

Прототип портала организации цифровых рабочих мест на проектах: паспорт проекта, шаблоны рабочих мест по ролям, заявки в сервис-деск, изоляция ИИ-контекста, отзыв доступов при закрытии.

Всё приложение — один файл [`index.html`](index.html), без сборки и зависимостей. Данные моковые и хранятся в браузере (`localStorage`).

## Как посмотреть

- Открыть `index.html` в браузере.
- Или развёрнутую версию на Vercel.

На экране входа выберите роль: руководитель ЦК, руководитель проекта, служба поддержки или сотрудник. Пароль не нужен. Сбросить демо-данные можно внизу боковой панели.
